# Verifier workspace

Checks for a paper do not live in this folder. They live in the run:

```
runs/<paper-slug>/verify/
  checks/
  PLAN.md
  RESULTS.md
```

The Verifier writes only under that `verify/` directory. It does not edit the paper, `equations.json`, or the Writer's files. `RESULTS.md` is generated by `verify_run.py`. The specimen run is `runs/example-oscillator/`.
